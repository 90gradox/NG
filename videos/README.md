# Video de fondo local

Guarda aquí el video que quieres reproducir automáticamente, sin audio, como fondo de la sección **Imágenes en movimiento**, con este nombre exacto:

`showreel.mp4`

Recomendado: MP4 (H.264), horizontal 16:9, sin audio o con audio silenciado. Solo reemplaza el archivo y conserva el mismo nombre; no hace falta modificar el código.
